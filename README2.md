# Expense Tracker

## Overview
The **Expense Tracker** is a basic Python command-line application that helps users record and manage their daily expenses.

It allows users to add expenses, view saved records, calculate total spending, and see category-wise summaries.

---

## Features
- Add daily expenses
- Store expenses in a file
- View all expense records
- Calculate total expenses
- Category-wise expense summary
- Simple menu-driven interface

---

## Technologies Used
- Python
- File handling
- Lists and dictionaries
- datetime module
- Conditional logic

---

## How It Works
1. User selects an option from the menu  
2. Expense data is stored in a text file  
3. Program reads data when needed  
4. Calculations are done dynamically
